NTE log tool

Decrypt or encrypt NTE log files using the game's built-in key. This is for NTE only. For WuWa logs, use Arglax's decryptor.

Choose a file to begin.
Cipher details

AES-256-ECB with a fixed key, PKCS#7 padding, and UTF-8 text. Each non-empty line is one Base64 string. Decrypting removes a trailing |SPLIT| marker; encrypting adds it back unless you turn it off. Downloaded files are named decrypted_ or encrypted_ followed by the original name.
